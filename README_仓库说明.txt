================================================================
《蓝的回信》资产仓库说明 README
================================================================
本仓库是《蓝的回信》全片制作的总资产库。目录结构与《00_文档/04_
资产库_生图提示词.txt》的编号体系一一对应：任何新资产先查编号，
再放进对应文件夹，按命名规范改名。

----------------------------------------------------------------
一、目录总览
----------------------------------------------------------------
00_文档/            剧本、分镜、提示词库、状态清单、制作日志
01_角色资产/        C01-C07，每角色三件套：三视图/定妆图/状态变体
02_场景资产/        S01-S07，每场景按光态分子目录（昼/暮/夜…）
03_道具资产/        P01-P07，多视图道具表
04_分镜首帧/        47个镜头的首帧图，按镜号命名；_reject废稿
05_视频片段/        47个镜头的生成视频，按镜号命名；_reject废片
06_音频/            01对白旁白 / 02音乐 / 03音效
07_剪辑工程/        剪映/Resolve工程文件与代理素材
08_交付/            01成片 / 02海报(竖版3:4) / 03创作说明 / 04承诺书
09_参考素材/        外部收集的澳门实景、瓷砖纹样、醒狮后厨参考图
99_工作流截图/      全程生成界面截图（创作说明举证材料，随手存！）
GIT协作规范.txt     推送/拉取规范（每次push/pull前必读，含四条红线）
AGENTS.md           AI协作交接协议

----------------------------------------------------------------
二、命名规范（所有文件强制遵守）
----------------------------------------------------------------
通用格式：[资产编号]_[名称]_[状态/用途]_[版本].png
  正确示例：C01_阿澄_三视图_v2.png
           S01_艺术空间_暮态_v1.png
           P04_完成版画作_发光态_v1.png
分镜产物：[镜号]_[用途]_[版本].ext
  正确示例：S13_首帧_v3.png        （第13镜首帧第3版）
           S13_视频_v2.mp4         （第13镜生成视频第2版）
注意：
  · 版本号 v1 v2 v3 只增不改——旧版不删除，除非明确作废进_reject
  · 状态词从资产库文档里复制（昼态/暮态/夜态/厨房态/展览态…），
    不要自造同义词（"白天"≠"昼态"）
  · 镜号 S01-S47 与分镜剧本一一对应，永不重排

----------------------------------------------------------------
三、新资产归档五步（后续每张图都走这个流程）
----------------------------------------------------------------
0. 先同步：git pull --ff-only origin main（详见 GIT协作规范.txt）
1. 查编号：在《00_文档/04_资产库_生图提示词.txt》里找到该资产的
   C/S/P编号；若是分镜首帧，查分镜剧本的镜号。
2. 放对位：
   · 角色 → 01_角色资产/C0X_名字/三视图|定妆图|状态变体/
   · 场景 → 02_场景资产/S0X_名字/对应光态/
   · 道具 → 03_道具资产/P0X_名字/
   · 分镜首帧 → 04_分镜首帧/（废稿进 _reject）
   · 生成视频 → 05_视频片段/（废片进 _reject）
   · 实拍参考、网上找的素材 → 09_参考素材/（与生成资产隔离！）
3. 改名入库：按第二节命名规范改名；随后在
   《00_文档/05_资产状态清单.txt》里按四档口径更新状态。
4. 提交推送：按 GIT协作规范.txt 执行 add/commit/push——
   禁止新建顶层目录，仓库结构与本文件第一节保持唯一一致。

----------------------------------------------------------------
四、验收与版本纪律（从资产库文档落实到位）
----------------------------------------------------------------
· 角色资产验收：10张同提示词出图≥7张像同一人才算合格；
  三视图必须过"单脸检查"（全表只留一个清晰正脸）。
· 场景资产验收：人能走进去、门能推开、光源方向唯一。
· 版本升级：同一资产重做=v2起版本号累加，v1保留原地不动；
  彻底作废=移入对应 _reject 文件夹，不直接删除。
· 分镜首帧命名必须带镜号——剪辑对账时按镜号找图，找不到=扣自己
  的时间。
